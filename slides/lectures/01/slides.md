# Notation

- *name* - this is a name
- **important** - this is important
- `command` - this is a command or a part of a source code


Code
```bash
$ command arguments
this is what the command wrote
$ command2 arguments
```

> `$` sigifies that the user can write a command, but is **not part of the command**.
